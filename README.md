**Video Scene Swap Studio**

Приложение для замены фона в видео через AI + набор независимых инструментов для QA, конвертации и семантического поиска футажей.

**Что умеет:**

* Заменяет фон в видео через Hugging Face Space (innova-ai/video-background-removal) — поддерживает видео и картинки в качестве фона  
* Работает через графический интерфейс Tkinter  
* Конвертирует видео в разные форматы и разрешения через ffmpeg — с выбором разрешения, кодека, аудиокодека
* Проверяет готовое видео через QA-агента (Gemini): оценивает узнаваемость персонажа, соответствие сцены, ставит оценку 1–10, выдаёт рекомендации  
* Индексирует папку с футажами: каждое видео описывается Gemini, генерируется эмбеддинг (через Gemini Embedding 2), метаданные сохраняются в виде JSON-файла  
* Ищет по смыслу среди проиндексированных футажей — текстовый запрос → косинусное сходство → топ результатов с описанием  

**Требования:**

* Python 3.10+  
* ffmpeg  
* Hugging Face API токен  
* Google Gemini API  

**Структура проекта:**

* executor.py — точка входа, GUI-приложение на Tkinter, обработчики всех вкладок  
* qa_agent.py — QA-агент: проверка видео через Gemini (персонаж, сцена, качество, рекомендации)  
* footage_indexer.py — индексация папки с видео: описание + эмбеддинг через Gemini, поиск по смыслу  
* run_background_swap.py — CLI-пример замены фона без GUI  
* check_api.py — просмотр API эндпоинтов Hugging Face Space  
* requirements.txt — зависимости Python 
* .env.example — пример файла с переменными окружения
