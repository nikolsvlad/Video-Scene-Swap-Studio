# Video Scene Swap Studio

Инструменты для автоматизации обработки видео: замена фона через AI, QA-проверка
результата отдельным агентом, конвертация через ffmpeg, семантическая индексация
банка футажей по эмбеддингам.

Собрано как рабочий прототип пайплайна для AI-видеопродакшена — без единой
монолитной "магической" функции: каждый агент независим, вызывается сам по себе
и может быть протестирован/заменён отдельно.

## Компоненты

| Файл | Роль | Модель/сервис |
|---|---|---|
| `executor.py` | GUI (Tkinter): связывает все агенты в одном окне | — |
| `qa_agent.py` | QA-агент: оценивает результат по видео (персонаж/сцена/качество) | Gemini (vision) |
| `footage_indexer.py` | Индексация банка футажей + семантический поиск | Gemini (описание) + Gemini Embedding 2 |
| `run_background_swap.py` | CLI-пример запуска замены фона без GUI | HuggingFace Space |
| `check_api.py` | Быстрая проверка доступных эндпоинтов HF Space | — |

## Архитектура

Каждый агент — независимый модуль с чистой функцией на входе/выходе, без общего
состояния. GUI (`executor.py`) — просто тонкая обёртка, которая их вызывает и
показывает прогресс. Это осознанный выбор: любой агент можно гонять из CLI,
из другого скрипта или заменить на другую модель, не трогая остальные.

```
Видео + фон ──▶ process_video() ──▶ результат
                                        │
                                        ▼
                              qa_agent.check_video()
                                        │
                                   прошло / нет ──▶ (при "нет": recommendation
                                                      для следующей попытки)
                                        │
                                        ▼
                              convert_video() (ffmpeg)

Банк футажей ──▶ footage_indexer.index_folder() ──▶ метаданные (_metadata/*.json)
                                                            │
Текстовый запрос ──▶ footage_indexer.search() ─────────────┘
                          (косинусное сходство по эмбеддингам)
```

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env  # впишите свои ключи HF_TOKEN и GEMINI_API_KEY
```

Для конвертации видео нужен установленный [ffmpeg](https://ffmpeg.org/download.html)
в PATH.

## Запуск

GUI:
```bash
python executor.py
```

CLI-пример (замена фона без интерфейса):
```bash
python run_background_swap.py
```

## Планы / что можно добавить дальше

- Агент-сценарист (LLM): текстовый запрос → сценарий + подбор футажей через `footage_indexer.search()`
- Оркестратор: автоматический цикл генерация → QA → повтор с учётом `recommendation`, если QA не прошло
- Метаданные и субтитры при конвертации (ffmpeg `-metadata`, Whisper → `.srt`)
